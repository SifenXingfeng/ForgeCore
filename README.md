# ForgeCore

ForgeCore 是一个面向智能工厂设计、生产仿真和资产治理的 Web 3D 初版。本仓库当前已经包含可运行前端、确定性生产链、36 个原创默认物品模型，以及已审计的第三方工厂资产。

## 本地运行

仓库中的 GLB、FBX、OBJ 和预览图片使用 Git LFS 保存。首次克隆前请确保已经安装 Git LFS，并执行：

```powershell
git lfs install
git lfs pull
```

Windows 用户可以直接双击仓库根目录的 [`启动ForgeCore.cmd`](<启动ForgeCore.cmd>)。脚本会自动定位项目、检查 Node/npm、在首次运行时安装依赖、检查 `4173` 端口、启动服务并打开浏览器。启动后请保持脚本窗口打开；按 `Ctrl+C` 或关闭该窗口即可停止服务。若 `4173` 被其他程序占用，可在终端运行 `启动ForgeCore.cmd 4175` 指定其他端口。

也可以手动运行：

```powershell
npm install
npm run dev -- --host 127.0.0.1 --port 4173 --strictPort
```

打开 `http://127.0.0.1:4173/`。首次进入先注册或登录，再从主菜单新建空白工厂；项目不会注入示范机器、物品、配方或存档。点击顶部“保存”可将当前账户的工厂和仿真状态保存到本地浏览器。

## 验证

```powershell
npm run check
npm run build
```

## 当前范围

- 运行总览、3D 工厂编辑、物品模型、配方、仿真、物流仓储、资产与许可七个页面；
- 单楼层网格工厂、对象增删/拖动/旋转/碰撞校验，以及用户自行建造的生产链；
- 固定步长仿真、1×/2×/5×/10×速度、指标、库存、事件及本地保存恢复；
- 36 个 first-party 参数化基础模型与第三方资产审计状态。

AGV 和无人机原件已入库，但正式 derived 运行时资产尚未完成，因此初版只使用程序化视觉代理并标记为规划态。权威范围、阶段和技术约束请以 [ForgeCore 项目方案.md](<ForgeCore 项目方案.md>) 为准。
